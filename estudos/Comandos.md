
# lsblk
Lista informação sobre dispositivos de bloco.
```bash
sudo lsblk
```

Exemplo de saída
```plaintext
sdb                     8:16   1  64,1M  0 disk /media/jvcm/DAPLINK
```

---
Após conectar com a placa é interessante visualizar o arquivo `DETAILS.txt`

# cat/bat

```
bat /media/jvcm/DAPLINK/DETAILS.TXT
```
